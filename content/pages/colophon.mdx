Set in Martian Grotesk (variable, weight and width axes) for display, Switzer for text and Geist Mono for the console. Built with Next.js 16, React 19, TypeScript and Tailwind CSS 4, content in MDX typed with Content Collections. Motion with GSAP and Lenis, one WebGL surface drawn by a hand-written WebGL2 shader. Tested with Vitest, Playwright and axe. Source on GitHub.
