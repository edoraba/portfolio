## 4. Architecture you must know

- Layout system: `components/sheet/{sheet,cell,rule,plate-number,span}.tsx`. A `Sheet` is a full-bleed grid with named lines `c 1..13` (12 columns at 1024 and up, 6 at 768, 4 below; tokens `--page --gap --cols --cell-pad` in `app/globals.css`, mirrored by `lib/sheet.ts` and checked by `tests/unit/sheet.test.ts`). `Cell` takes `col`, `end` (desktop lines), optional `md`/`sm` overrides, `row`, hairline flags `l r t b`, `flush`. Spans are emitted as CSS variables (`--cs --ce --cs-md ...`) so Tailwind never needs to see class names. Hairlines are pseudo-elements and gradients that draw in when the cell gets `is-drawn` (`lib/motion/rules.ts`, mounted once by `components/sheet/rules-observer.tsx`).
- Themes: `lib/themes.data.mjs` (data) plus `lib/themes.ts` (types, `nextTheme`), generator `scripts/gen-themes.mjs` writes `app/themes.css` (prettier-ignored, committed, parity tested). `data-theme` on `<html>` holds the theme name; `public/theme.js` (sync in head) applies it pre-paint and also sets `data-motion` and the `js` class. Legacy `dark`/`light` map to `field`/`paper`. The field shader reads `--field-on/--field-off/--accent`.
- Console header: `components/console/*` (site-header, nav-cells, console-line, theme-swatches with the view-transition sweep, mobile-menu, monogram, hotkeys for G, T, Escape, console-plate to set the readout on inner pages). Store `lib/console-store.ts`; plates registry `lib/plates.ts` with `usePlate(id, ref)` for the home.
- Loader: `components/loader.tsx` plus pure logic in `lib/loader.ts` (steps fonts, shader, content, images; min 600, max 1200, cap 1500). Field mode `calibrate` renders the field unmasked with floor 0.35; `FieldMount` mounts immediately when the loader requests it. Dispatches a `calibrated` window event; `HeroMask` widens the words 78 to 100 on it.
- Field: `lib/field/*` (gl, shader, renderer, store with `request(id)/release(id)`, quality tiers, pointer smoothing, support checks). Modes hero (masked), band (footer, menu, about), calibrate, off. Only one WebGL surface, ever. The ownership model is currently broken and Plan 07 Task 1 replaces it with priority claims.
- Home plates: `components/plates/*`, one file per plate, all wrapped by `plate.tsx` which places the mono number and registers the section in `lib/plates.ts`. That registry runs one 10Hz loop and names the plate covering the middle of the screen in the console header; intersection ratios are ambiguous once sections are pinned, which is why it is a centre test and not an observer. Scroll maths lives in `lib/motion/scrub.ts` (`pinLength`, `beatAt`, `itemProgress`), the cloth lattice in `lib/motion/cloth.ts`, the physics helpers in `lib/physics/toolbox.ts` (Matter.js is imported only when the plate is within a screen).
- Brand: `components/console/monogram.tsx` is Edoardo's own EB mark, ten rectangles on a modular grid (bar 175.355, void 236.967, in a 1000 square) grouped in five parts. The loader fills one part per resource that becomes ready. The source SVGs came from his Figma file `Delta3-Mockup`, node 186-2.
- Motion: `lib/motion/gsap.ts` (`setupGsap`, eases `editorial` and `wipe`), `line-reveal.tsx`, `decode.tsx`, `slice-flip.ts` plus `flip-text.tsx`, `smooth-scroll.tsx` (Lenis, only home and /work), `page-transition.tsx`.
- Content: `content-collections.ts`, `lib/content.ts`, MDX under `content/` (work, lab, writing, pages). Works have `order`, `client`, `year`, `role`, `team`, `stack`, `status`, `links`, `headings`, optional `cover`.

## 5. Gotchas that cost time

- Tailwind 4 utilities live in `@layer utilities`; unlayered component CSS beats them. Put component CSS in `@layer components` or `hidden`/`lg:block` stop working (this broke the header once).
- Anything read from localStorage or the DOM must not shape server markup (grid overlay, theme, motion). Render after `useMounted()` or React throws the document away on hydration and `theme.js` attributes are lost. `tests/e2e/hydration.spec.ts` guards it.
- `next/script` with `beforeInteractive` runs after first paint in the App Router; the head script is a plain sync `<script src="/theme.js">`.
- The React Compiler lint rule forbids synchronous `setState` in effects: derive state in render (`useMemo` on `mounted`) or defer with `queueMicrotask`.
- `Decode` requires a single string child; use a template literal.
- Headless Chromium has no hardware WebGL: the field falls back to the static dither and the loader never shows in e2e. Test those with `scripts/console-check.mjs` (headed, `--use-angle=d3d11`).
- Bricolage Grotesque on Google Fonts has no italic; the hero italic is synthesised.
- Dev-only noise: Next "instant validation" bundler errors appear in dev logs, not in production.
- Lighthouse: desktop is green (`lighthouserc.json`), mobile sits at 0.85 (`lighthouserc.mobile.json`) held back by LCP 3.9s. Both run in CI.
- Playwright reuses a server already listening on 3100 (`reuseExistingServer`), so a stale `pnpm start` will make you test an old build and chase ghosts. Kill it first: `Get-NetTCPConnection -LocalPort 3100 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }`.
- Cell hairlines are drawn with background longhands on purpose (`app/globals.css`). Using the `background` shorthand anywhere on `.cell` wipes the cell's own colour, which is how the work covers ended up transparent.
- An element that translates out of its cell still counts as an obstruction for axe target-size even when the parent clips it. Reveal with `clip-path`, not with a translate that leaves the box.
- SVG coordinates computed with `Math.*` must be rounded to fixed precision or the server and the browser disagree on the last digit and React reports a hydration mismatch (this happened with the tunnel rays).
- A nested composition stays on the grid with `<Sheet nested>` (class `subsheet`): the same named column lines without the page gutter tracks. It only aligns when the wrapper spans the full content width.
- Pinned plates must start below the sticky console (`headerHeight()` in `lib/sheet.ts`) and must fit `100dvh - var(--header-h)`.
